## 1) Классификация данных (ISO/IEC 27001/27002)

### Публичные данные
- Описание объектов и проектов, фотографии/визуализации, публичные 3D/онлайн‑туры.

### Внутренние данные
- Регламенты и инструкции, карты процессов, схемы интеграций, C4‑диаграммы, конфигурации инфраструктуры/приложений.

### Конфиденциальные данные

- Персональные данные клиентов/собственников (ФИО, контакты, удостоверяющие документы), анкеты, заявки, бронирования, договоры/сделки.
- Платёжные реквизиты, начисления и оплаты ЖКУ.
- Данные «умного дома», если привязаны к квартире/профилю и позволяют косвенно идентифицировать поведение человека.

### Секретные данные
- Секреты/ключи (KMS/HSM), приватные ключи TLS, JWT‑секреты, пароли/ключи сервис‑аккаунтов, секреты CI/CD.
- Токены/ключи интеграций с госорганами/УК/платёжными провайдерами, закрытые API‑спецификации.
- Дампы БД/резервные копии с персональными данными в полном объёме.
- Коммерчески чувствительная информация до релиза (стратегии ценообразования, условия эксклюзивных сделок).

## 2) Риски и их оценки (Незначительный / Значительный / Критический)


| Категория         | Риск              | Оценка        | Обоснование кратко |
|-------------------|-------------------|---------------|--------------------|
| **Публичные**     | Утечка            | Незначительный| Данные предназначены для публикации; ущерб минимален. |
|                   | Потеря            | Незначительный| Можно восстановить из CMS/репозитория/кэша. |
|                   | Искажение         | Значительный  | Подмена контента на витрине вводит в заблуждение клиентов. |
|                   | Некачественные    | Значительный  | Неверные цены/сроки → потери продаж/жалобы. |
|                   | Обесценивание     | Незначительный| Быстро устаревают, но влияние на бизнес умеренное. |
| **Внутренние**    | Утечка            | Значительный  | Раскрытие конфигураций и внутренних артефактов. |
|                   | Потеря            | Значительный  | Усложняет поддержку/инцидент‑менеджмент; задержки. |
|                   | Искажение         | Значительный  | Неверные конфиги/инструкции → сбои и ошибки. |
|                   | Некачественные    | Значительный  | Ведёт к ошибочным решениям и ре‑ворку. |
|                   | Обесценивание     | Значительный  | Быстрое устаревание → рост технического долга/рисков. |
| **Конфиденциальные** | Утечка         | Критический   | Регуляторные риски, иски, репутационный ущерб. |
|                   | Потеря            | Критический   | Невозможность вести расчёты/сделки, срыв обязательств. |
|                   | Искажение         | Критический   | Ошибочные начисления/договора приводят к прямым ущербам и штрафам. |
|                   | Некачественные    | Значительный  | BI/ML/аналитика и операционные процессы деградируют. |
|                   | Обесценивание     | Незначительный| Сама ценность персональных данных для бизнеса сохраняется, но риск низок. |
| **Секретные**     | Утечка            | Критический   | Ключи/секреты → компрометация систем, массовые инциденты. |
|                   | Потеря            | Критический   | Потеря ключей/доступов → простой/невозможность расшифровки. |
|                   | Искажение         | Критический   | Подмена сертификатов, секретов |
|                   | Некачественные    | Значительный  | Слабые алгоритмы или длины ключей → повышенный риск взлома. |
|                   | Обесценивание     | Значительный| Косвенно приводит ко всем другим рискам |
